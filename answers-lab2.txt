b. We have placed the kernel and user environment in the same address space. Why will user programs not be able to read or write the kernel's memory? What specific mechanisms protect the kernel memory?
Answer: The disabling of the PTE_U bit in the page table protects the kernel memory from user programs.

c. What is the maximum amount of physical memory that this operating system can support? Why?
Answer: The kernel address space is the range of memory allocated for the system. Since the range is 0xf0000000->0xffffffff, this leaves the maximum at 256MB.

d. How much space overhead is there for managing memory, if we actually had the maximum amount of physical memory? How is this overhead broken down?
Answer: The overhead needs to account for PageInfo structs (4MB), page directory (4KB), and page table entries (2MB), totaling 4MB+2MB+4KB.
